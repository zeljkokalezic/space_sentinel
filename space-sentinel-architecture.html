Space Sentinel Architecture

Vite + React + Three.js roguelike space shooter — modular game engine with systems architecture

React UI Layer

  • • App.jsx — orchestrator with gameState machine
  • • 12+ overlay/screen components (pure UI)
  • • useGameLoop — raf loop + Three.js init
  • • useInput — keyboard/pointer/ESC handler

Game Engine

  • • 15 systems: movement, weapons, enemies, AI
  • • 3 mission-specific: escort, beacon, sabotage
  • • No React imports — explicit (dt, g, cbs) params
  • • physics.js delegates to all systems each tick

Rendering + Audio

  • • renderer3d.js — Three.js chase camera, mesh cache
  • • renderer2d.js — Canvas HUD (HP, radar, joystick)
  • • SoundManager — 13 procedural SFX via Web Audio API
  • • audio.js — procedural SFX + soundtrack layers
