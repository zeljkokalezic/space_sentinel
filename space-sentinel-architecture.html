Space Sentinel Architecture

Vite + React + Three.js Game Engine Architecture

React UI Layer

  • • App.jsx Orchestrates Game State
  • • 7 Overlay Components (Map, Shop, Events, etc.)
  • • Custom Hooks (useGameLoop, useInput)
  • • Isolated from Engine Logic

Game Engine Layer

  • • physics.js: Simulation Orchestrator
  • • renderer.js: 3D (Three.js) + 2D (Canvas HUD)
  • • combat.js, spawner.js, state.js, mapGenerator.js
  • • No React Imports - Pure Game Logic

Physics Systems

  • • 9 Independent System Modules
  • • Explicit Parameters (No Global State)
  • • Direct Game State Array Mutation
  • • playerMovement, weapons, enemies, projectiles, etc.
