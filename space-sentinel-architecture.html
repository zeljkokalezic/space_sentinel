Space Sentinel Architecture

Vite + React orchestrator wrapping a modular vanilla Three.js game engine

React Orchestrator Layer

  • • App.jsx owns all game state (gameState, uiScrap, uiLevels)
  • • useGameLoop manages Three.js scene + rAF animation loop
  • • useInput handles keyboard, pointer, and touch joystick
  • • 10+ overlay components render conditionally on gameState
  • • Dev mode toggled via backtick key for mission testing

Engine + Physics Systems

  • • physics.js delegates to 20+ isolated system modules
  • • Each system receives explicit params (no global state reads)
  • • bossCore shared by full boss + mini-boss wrappers
  • • Direct array mutation on game state for performance
  • • Mission setup modules reusable across dev + normal play

Rendering + Data Layer

  • • renderer3d.js: Three.js InstancedMesh + shared geometries
  • • renderer2d.js: Canvas 2D HUD overlay (crosshair, HP vignette)
  • • Constants isolated for mod-safe editing without engine changes
  • • Settings persisted via localStorage (space_sentinel_settings)
  • • 9 boss attack patterns as pure functions in lookup table
