## Phase 1: Critical bugs (crash / game-breaking)

### 1. weapons.js:96,101 — `completeMission` / `createParticles` undefined
**File:** `src/engine/systems/weapons.js`
**Root cause:** Point defense kill handler calls `completeMission()` and `createParticles()` without importing them.
**Fix:**
- Add `completeMission` as a parameter to `updateWeapons(dt, g, completeMission)`
- Import `createParticles` from `../combat`
- Update call site in `physics.js` line 82: `updateWeapons(dt, g, completeMission)`
- Add `id: Math.random()` to pickup on line 103 (matches enemies.js pattern)

### 2. sabotage.js:80-85 — Pickup property mismatch (`scrap` vs `value`, missing `radius`)
**File:** `src/engine/systems/sabotage.js`
**Root cause:** Pickup uses `scrap` property instead of `value`, and omits `radius`. `pickups.js` reads `p.value` (undefined) and `p.radius` (undefined), causing NaN collision check.
**Fix:** Change line 80-85 to:
```js
g.pickups.push({
  id: Math.random(),
  x: s.x + (Math.random() - 0.5) * 30,
  y: s.y + (Math.random() - 0.5) * 30,
  value: cfg.scrapPerDestroy,
  active: true,
  radius: 6,
});
```

### 3. beacon.js:17 + mission.js:44-46 — Defend timer double-counted
**File:** `src/engine/systems/beacon.js` (line 17), `src/engine/systems/mission.js` (line 44)
**Root cause:** Both `updateBeacon` and `checkMissionProgress` increment `g.mission.current += dt` for defend missions.
**Fix:** Remove `g.mission.current += dt` from `beacon.js:17`. `checkMissionProgress` already handles defend timer. Also remove the `if (g.mission.current >= g.mission.target) completeMission()` from beacon.js since `checkMissionProgress` handles it.

### 4. renderer3d.js:214-217 — LOD scale cumulative per frame
**File:** `src/engine/renderer3d.js`
**Root cause:** `m.scale.multiplyScalar(0.8)` runs every frame, compounding. After 30 frames enemy is invisible.
**Fix:** Store original scale on mesh creation, apply LOD as absolute scale:
```js
// In getMesh callback, store original scale
// Then in LOD block:
if (dist > 1000) {
  const s = e.radius;
  m.scale.set(s * 2 * 0.8, s * 2 * 0.8, s * 0.8);
}
```
Or simpler: only apply when enemy was previously at full distance:
```js
if (dist > 1000 && !m.userData.lodApplied) {
  m.scale.multiplyScalar(0.8);
  m.userData.lodApplied = true;
} else if (dist <= 1000 && m.userData.lodApplied) {
  // Restore — divide by 0.8
  m.scale.multiplyScalar(1.25);
  m.userData.lodApplied = false;
}
```

### 6. escort.js:38,88 — Stale distance check
**File:** `src/engine/systems/escort.js`
**Root cause:** `distToTarget` computed before movement (line 38), checked after (line 88).
**Fix:** Recompute distance after movement block:
```js
// After movement + evasion + clamping (lines 47-85):
const finalDist = Math.hypot(esc.targetX - esc.x, esc.targetY - esc.y);
if (finalDist <= C.escort.destinationThreshold) {
  completeMission();
}
```
Also update mission progress with `finalDist` instead of stale `distToTarget`.

### 7. renderer2d.js:65 — Division by zero for escort mission progress

const mProg = g.mission.target > 0

  : 0;
